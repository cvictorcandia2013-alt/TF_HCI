# PeakSet - Proyecto Final de HCI

## 1. Descripción del proyecto

PeakSet es un prototipo de aplicación web desarrollado para el curso de Interacción Humano-Computador (HCI). Permite registrar entrenamientos, consultar rutinas y visualizar el progreso físico mediante una interfaz diseñada para atletas y entrenadores.

## 2. Objetivo

Desarrollar una plataforma intuitiva y accesible que facilite la gestión de entrenamientos, aplicando principios de usabilidad y experiencia de usuario.

## 3. Tecnologías utilizadas

- **HTML5:** estructura de la página.
- **CSS3:** diseño y adaptación a diferentes dispositivos.
- **JavaScript:** funcionalidades e interacciones.
- **GitHub:** control de versiones y colaboración.
- **GitHub Pages:** publicación del prototipo.

## 4. Estructura del repositorio

- `index.html`: página principal.
- `css/`: estilos de la interfaz.
- `js/`: funcionalidades del sistema.
- `assets/`: imágenes y recursos gráficos.
- `docs/`: documentación del proyecto.

## 5. Despliegue en GitHub Pages

El prototipo se encuentra publicado mediante GitHub Pages y puede visualizarse desde cualquier navegador.

**Enlace:** [Visualizar PeakSet](https://cvictorcandia2013-alt.github.io/TF_HCI/)

## 6. Pruebas de aceptación

Se realizarán pruebas para verificar el funcionamiento de las principales características del prototipo, considerando:

- Navegación entre secciones.
- Registro de entrenamientos y consulta de rutinas.
- Funcionamiento de botones e interacciones.
- Adaptación a dispositivos móviles.
- Accesibilidad y facilidad de uso.

Los resultados se registrarán en una matriz de pruebas, incluyendo el estado de cada caso y las observaciones encontradas.
